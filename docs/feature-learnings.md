# Feature Learnings

Curated, verified guidance that applies across more than one feature. Detailed
evidence remains in the linked feature worklog.

## Entry Format

### <Short lesson>
- Source worklog: `docs/worklogs/<feature-slug>.md`
- Verified by: <command, review, or repository evidence>
- Applies when: <scope or trigger>
- Guidance: <actionable practice>
- Review trigger: <condition that may make this outdated>
- Status: active | **superseded** by <replacement and reason>

## Update Rules

- Add an entry only when the learning is verified, reusable, and actionable.
- Do not add transient debugging notes, feature-specific detail, unverified
  hypotheses, secrets, or duplicated worklog evidence.
- Retain a link to the originating worklog for context and auditability.
- Mark outdated entries as **superseded** in place; do not delete them.
